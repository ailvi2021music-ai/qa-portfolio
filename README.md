# QA Portfolio

This repository contains practical QA artifacts created during independent QA practice.

## Skills
- Manual QA
- Test Design
- Bug Reporting
- API Testing (Postman)
- UI vs API analysis
- Browser DevTools (Network, Console)
- Jira

## Portfolio Structure

- bug-reports/
  Bug reports with clear reproduction steps and expected vs actual results.

- test-cases/
  Test cases for core web application features.

- checklists/
  QA checklists for common testing scenarios.

- postman/
  Postman collections used for API testing.

- devtools-evidence/
  Screenshots and notes from browser DevTools analysis.

- swagger-notes/
  Notes comparing API contract with actual behavior.
